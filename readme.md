# Родопите отблизо (Rodopite otblizo)

Уеб приложение за забележителности, места за настаняване, местни производители и пътеписи в Родопите, изградено с Django и Django REST Framework.

## Основни модули
- `accounts` — разширен потребителски модел (`AppUser`), потребителски профил (`UserProfile`), любими забележителности, автентикация и роли/групи.
- `destinations` — забележителности в Родопите, категории, трудност и REST API ендпоинт.
- `accommodations` — места за настаняване, капацитет, цени и връзки към близки забележителности.
- `producers` — местни производители и занаятчии по категории продукти и населени места.
- `community` — пътеписи от пътувания, харесвания и асинхронни известия с Celery.
